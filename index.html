1. 概述

BiuEcho（下称「本扩展」或「本服务」）用于在用户选定的 AI 对话网页上，按用户配置自动投放提示词，采集回复内容与截图，并可选进行关键词匹配，以评估品牌或关键词在 AI 回答中的可见度。

本政策说明我们如何收集、使用、存储、共享与保护相关用户数据。使用本扩展即表示您知悉本政策所述做法。若您不同意，请停止使用并卸载本扩展。

2. 运营方与联系方式

  • 产品名称：BiuEcho
  • 数据服务域名（默认）：https://geo.3biu.cn
  • 联系邮箱：service@3biu.cn

如需查阅、更正、导出或删除与您账号相关的云端数据，或对本政策有疑问，请通过上述邮箱联系我们。

3. 我们收集哪些数据

根据您使用免费版或付费版，以及您开启的检测选项，本扩展可能处理下列数据：

3.1 个人身份信息：付费账号登录时使用的电子邮件地址；账号相关的客户/套餐标识。

3.2 身份验证信息：邮箱登录密码（经 HTTPS 传输）；访问令牌/凭证。

3.3 网站内容与用户生成内容：提示词正文及备注；AI 回复全文与 HTML；视口截图与对话区长截图；可选关键词及匹配结果。

3.4 网络记录（与检测相关）：检测涉及的 AI 平台名称、页面 URL/域名及检测时间等元数据。仅服务于您主动发起的检测任务。

3.5 位置相关信息：与服务器通信时可能处理的 IP 地址及大致网络区域信息（用于安全、防滥用、运维与故障排查）。

3.6 其他运行数据：本机配置、安装标识、检测批次/轮次状态、执行日志摘要；付费版可选上报的异常现场信息。

我们不通过本扩展收集健康信息或信用卡号等财务付款卡信息，也不将本扩展用于信用评估。

我们仅将数据用于提供与改进 BiuEcho 的单一用途，包括：完成您发起的可见度监测；账号鉴权与授权；结果展示/筛选/导出；安全与支持；履行法律义务。

我们不会将用户数据用于与单一用途无关的目的，不会用于确定信用度或贷款资格，也不会向第三方出售用户数据。

7. 保留期限

本机数据：直至您清除扩展数据、卸载扩展，或达到本地历史/提示词上限被轮换删除。

11. 国际传输

数据可能在我们或服务商运营的相关法域进行处理。我们将在适用法律要求的范围内采取适当保护措施。

12. Chrome 网上应用店用户数据政策（Limited Use）

本扩展对用户数据的使用将遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求：仅将所收集的用户数据用于提供或改进本扩展的单一用途功能，不为无关目的出售或转移用户数据，不为信用评估或贷款目的使用用户数据。

13. 政策更新

我们可能不时更新本政策并修改文首生效日期。继续使用本扩展即视为知悉更新后的政策。
